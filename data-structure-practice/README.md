# STEP SEM-3 Category C: Data Structure Practice Solutions

This directory contains solutions for the **STEP SEM-3 Category C Data Structure Practice** module:
- 10 Data Structure and Algorithm Problems (Strings, Arrays, Number Theory, Loops, OOP)
- Part B Quiz (Q1–Q20) with verified answers in `QLA_SOLUTIONS.md`
- Part C Concept Questions (Q1–Q10) with detailed answers in `QLA_SOLUTIONS.md`

## Problem Directory

1. `VowelConsonantCounter.java`: Counts vowels and consonants in a word.
2. `WordReverserPalindrome.java`: Reverses text with `StringBuilder` and checks palindrome.
3. `EvenOddCounter.java`: Counts even and odd numbers in a list.
4. `InPlaceArrayReversal.java`: Two-pointer in-place array reversal.
5. `DigitSumAndReversal.java`: Digit extraction, summation, and number reversal.
6. `PrimeNumberChecker.java`: Primality test up to $\sqrt{n}$.
7. `FactorialCalculation.java`: Calculates $n!$ with `BigInteger`.
8. `StudentGradeAssignment.java`: Student grading ladder.
9. `LeapYearDetector.java`: Leap year algorithm.
10. `StudentResultCardGenerator.java`: Student OOP model with average and grade computation.
